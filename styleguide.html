05

Buttons & CTAs

Primary — .hero-cta-primary

Solid mint fill. Used for primary actions. Works on both dark and light backgrounds.

View my work Hover state
View my work Hover state
<a href="..." class="hero-cta-primary">View my work</a> Default: mint bg (#69fbc8), dark text (#1a2024), 6px radius, 12px 22px padding Hover: opacity 0.85

Ghost / Nav CTA — .nav-cta

White border, white text. For use on dark surfaces only — nav and dark backgrounds.

Let's talk Let's talk (hover)
<a href="..." class="nav-cta">Let's talk</a> Default: white text, rgba(255,255,255,0.4) border Hover: mint text + mint border (--color-brand) Dark surface only — do not use on light backgrounds

Secondary / Text — .hero-cta-secondary

Underline link style. For use on dark surfaces as a paired secondary action alongside primary.

Connect on LinkedIn → Hover state
<a href="..." class="hero-cta-secondary">Connect on LinkedIn →</a> Default: rgba(255,255,255,0.65) text, rgba(255,255,255,0.3) underline border Hover: rgba(255,255,255,0.85) text, rgba(255,255,255,0.5) border Dark surface only

Prose link — p a, li a, figcaption a

Teal underline. Scoped to paragraph, list, and figcaption content on light surfaces only.

Brokers spent the majority of their time on manual data verification rather than strategic work.

On hover: highlighted text with mint background.

p a, li a, figcaption a Default: color-brand-dark (#0a8f68), underline, 3px offset Hover: color-dark text, mint bg (#69fbc8) Light surface only — scoped to prose contexts
